# Agentic URL Shortener: Orchestration-First SDLC

## Quick Start

```bash
mvn clean compile
mvn test
mvn spring-boot:run
```

## Project Structure

- `src/main/java/com/shortener/orchestrator/` - Orchestration engine
- `src/main/java/com/shortener/urlshortener/` - URL shortener application
- `src/test/java/com/shortener/` - Tests
- `specs/` - Requirements and scenarios
- `docs/` - Architecture documentation
